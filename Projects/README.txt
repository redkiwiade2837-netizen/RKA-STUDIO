이 폴더의 각 하위 폴더가 사이트의 프로젝트 한 개에 해당합니다.

폴더 이름 규칙: "번호 이름 (분류, 연도)"  (예: 008 Trunk House (Office, 2025))
- 번호/이름을 바꾸면 사이트에 표시되는 번호/제목도 그대로 바뀝니다.
- 괄호 안 "분류, 연도"는 둘 다 선택 사항입니다.
  - "008 Trunk House (Office, 2025)" → 분류 Office, 연도 2025
  - "008 Trunk House (2025)"         → 연도만 2025, 분류 없음
  - "008 Trunk House (Office)"       → 분류만 Office, 연도 없음
  - "008 Trunk House"                → 분류/연도 없음
  - 순서는 상관없습니다 ("2025, Office"도 동일하게 동작).
  - 이 값이 사이트 Projects 페이지의 Type / Year 사이드바 필터에 그대로 사용됩니다.
- 새 프로젝트를 추가하려면 같은 형식으로 폴더를 새로 만드세요.

각 프로젝트 폴더 안 Left / Right 폴더:
- "(.1.)" 이라는 이름의 파일 1장 → Projects 목록 카드에 쓰이는 대표 이미지
  (Left의 (.1.) = 기본 이미지, Right의 (.1.) = 마우스를 올렸을 때(hover) 보이는 이미지)
- "1", "2", "3"... 처럼 숫자로만 된 파일들 → 상세 페이지에서 클릭할 때마다
  순서대로 넘어가는 갤러리 (Left = 사진 쪽, Right = 도면 쪽). 마지막 이미지
  다음에 클릭하면 다시 1번으로 돌아갑니다.
- (.1.)과 숫자 파일은 서로 별개입니다 — 대표 이미지와 갤러리 1번을 같은
  사진으로 쓰고 싶다면 같은 이미지를 (.1.)과 1 두 파일로 각각 넣어주세요.

지원 형식: jpg, jpeg, png, webp, gif, avif
