이 폴더의 각 하위 폴더가 사이트의 가구 상품 한 개에 해당합니다.

폴더 이름 규칙: "번호 이름" (예: 001 BRUTALIST CHAIR)
- 앞의 번호와 이름을 바꾸면 사이트에 표시되는 번호/이름도 그대로 바뀝니다.
- 목록 페이지에는 번호가 큰 상품부터(내림차순) 표시됩니다.
- 새 상품을 추가하려면 같은 형식으로 폴더를 새로 만드세요 (예: 005 NEW CHAIR).
  단, 새로 만든 상품은 가격/설명 등 세부 정보를 rka-app/src/data/data.js 의
  furnitureMeta 안에 번호를 키로 추가해줘야 표시됩니다 (이미지는 바로 반영됩니다).
- 번호를 바꾸면(예: 001 → 005) data.js의 furnitureMeta에서도 해당 번호의
  가격/설명 항목을 같은 번호로 옮겨줘야 정보가 이어집니다.

각 상품 폴더 안:
- Left 폴더  → 기본으로 보이는 이미지 1장
- Right 폴더 → 마우스를 올렸을 때(hover) 보이는 이미지 1장
  (이미지가 여러 장이면 파일명 기준 첫 번째 이미지만 사용됩니다)

지원 형식: jpg, jpeg, png, webp, gif, avif
